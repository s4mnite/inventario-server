# Actualización móvil: Inventario y Ventas

- Inventario móvil más compacto y ordenado.
- Venta de productos con selector visual, buscador y filtros.
- Carrito con cantidades, subtotales y total.
- Métodos de pago: Efectivo, Tarjeta y Transferencia.
- Crédito eliminado del nuevo flujo de venta.
- Venta de huevos se mantiene independiente.
- Vista de escritorio anterior conservada; el rediseño se activa en celular.
