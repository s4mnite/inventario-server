# Actualización Inicio — degradado final

Cambios aplicados sobre `ReyDelHuevo-Inicio-Arreglado.zip`:

- Fondo móvil con degradado amarillo suave.
- Tarjeta de saludo con degradado, logo circular y sombra.
- Tarjetas blancas con sombras más suaves y consistentes.
- Tarjeta roja de ventas con degradado y profundidad.
- Se eliminan los bloques adicionales que no estaban en la maqueta final.
- Se conserva "Últimos movimientos".
- Se agrega botón grande "Nueva venta de huevos" con degradado amarillo/naranja y sombra.
- El botón abre el flujo existente de venta de huevos.
- No se modifica la lógica de inventario, ventas ni backend.

Nota: no fue posible ejecutar Vite en este entorno porque las dependencias npm no están disponibles en el registro interno. El cambio fue limitado a JSX y CSS del frontend.
