# Generar APK de Rey del Huevo

El proyecto usa Capacitor para convertir la aplicación web en una aplicación Android.

## Desde GitHub

1. Sube este proyecto a la rama `main`.
2. En GitHub entra en **Actions**.
3. Abre **Generar APK**.
4. Cuando termine, descarga el archivo **Rey-del-Huevo-APK**.
5. Dentro está `app-debug.apk`.

La aplicación se conecta al backend de Render:
`https://inventario-backend-ftw6.onrender.com`

La base de datos permanece en MongoDB; instalar o actualizar el APK no borra los datos.
