# Actualización venta de huevos por formato

Cambios aplicados únicamente al módulo de Huevos:

- Se eliminó la venta unitaria en el flujo móvil.
- Solo se permite vender por Bandeja de 30 huevos o Caja de 180 huevos.
- El selector muestra formato, cantidad de formatos, huevos totales y precio.
- El stock se descuenta en huevos.
- Los movimientos guardan formato, cantidadFormatos, bandejas/cajas y huevos.
- El formulario antiguo de venta solo permite múltiplos de 30.
